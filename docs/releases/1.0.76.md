## Компоненты

- Установка и обновление сборки Sing-box Extended снова работает: из-за потерянной вспомогательной функции выбор пакета из релиза падал с ошибкой «Failed to resolve sing-box-extended package release» на всех архитектурах (ломано с 1.0.62).
- Кнопка «Удалить Forkop X полностью» больше не отменяет удаление, если служба не смогла остановиться (сломанный или вручную заменённый sing-box, уже восстановленный dnsmasq): остановка теперь необязательна для продолжения, а неудачное пакетное удаление пакетов повторяется по одному, чтобы один «капризный» пакет не оставлял установленными остальные.

## Мониторинг

- Пинг групп (URLTest) больше не зависает в «NA»: ядро тестирует участников группы раундами, и таймаут запроса теперь учитывает число участников, а не обрывает проверку на половине.
- Ошибки контроллера (HTTP 400/503/504) считаются ошибками, а не успешным ответом: раньше JSON с текстом ошибки принимался за валидный ответ, и вечный «NA» оставался без объяснений.
- Автоматический замер пинга всех серверов не срывается из-за части недоступных: если ответил хотя бы один сервер, результат считается успешным, а недоступные отмечаются как не ответившие.

## Диагностика

- «Проверка сайта» больше не отвечает «Правило не рассчитано» на правилах с условиями AND/OR: логические правила теперь вычисляются, в том числе когда часть условий отвечает сразу (для AND достаточно одного «не подходит», для OR — одного «подходит»).
- Правила с исключёнными устройствами учитываются честно: если правило применяется только к выбранным устройствам, диагностика прямо пишет, что ответ рассчитан для них.
- Проверка принимает адреса из одной зоны (например, `ru` или `com`) — раньше такой ввод отклонялся как некорректный домен.
