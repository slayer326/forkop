## Исправление обновления подписок

- Исправлен редкий пропуск обновления подписки по расписанию: проверка, пришедшая на несколько секунд раньше часового интервала, больше не откладывает загрузку ещё на час.
- Допуск до 60 секунд действует только для подписок с интервалом от одного часа. Обновление списков и короткие интервалы работают как раньше.
