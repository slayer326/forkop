## Исправления клиента и интерфейса

- «Обзор», «Диагностика» и «История и восстановление» теперь используют всю ширину страницы. На широком экране карточки раскладываются по колонкам, на телефоне остаются в один ряд.
- Проверка больших SRS-списков больше не разворачивает их в JSON и расходует заметно меньше памяти.
- Исправлена маршрутизация голосового и видеотрафика Discord в общих диапазонах Cloudflare, включая UDP 443.
- Установщик ждёт освобождения `opkg`, а APK-пакеты при обновлении действительно переустанавливаются поверх текущей версии.
- Добавлена поддержка дополнительных полей Reality и xHTTP. Старый кэш подписки автоматически пересобирается, если в нём этих полей ещё нет.
- Ссылки подписок по-прежнему не привязаны к одному сервису: можно использовать любой корректный HTTPS URL.

После обновления откройте Forkop X с очисткой кэша браузера (`Ctrl+F5`).
