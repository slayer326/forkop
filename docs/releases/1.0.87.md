В «Мониторинг → Узлы и группы» теперь можно свернуть любую секцию нажатием на заголовок. Это упрощает переход между длинными списками узлов.

Браузер запоминает состояние каждой секции после обновления данных и перезагрузки страницы. Свёрнутые секции не отрисовывают плитки узлов.
