Стабильнее обновления подписок и переходы sing-box

- Обновление подписок переведено на staged-конфигурацию с backup и rollback:
  при ошибке публикации, запуска sing-box или auxiliary runtime предыдущий
  рабочий конфиг восстанавливается.
- Start/stop/reload sing-box выполняются через контролируемые переходы с
  проверкой procd-владельца, PID, времени запуска и отсутствия чужих или
  дублирующихся процессов.
- Добавлена защита package upgrade: Forkop запоминает точный управляемый
  sing-box перед установкой пакета и отказывается продолжать при неясном
  состоянии процесса.
- Улучшена синхронизация pending reload и automatic latency test: запросы не
  теряются, а worker уступает reload handoff.
- Runtime-логи удаляют userinfo, query и fragment из URL удалённых источников,
  сохраняя только безопасный host/path для диагностики.
- Исправлена генерация selector для URLTest-групп с дочерними outbound.
- Сохранена поддержка любых корректных HTTPS subscription URL без allowlist
  провайдеров и ограничений по подписке.
- Рабочим зеркалом остаётся `https://mirror.infotechtg.ru`; старый
  `mirror.51343.ru` используется только для миграции старых конфигураций и
  тестовых фикстур.
