## WARP через интерфейсы OpenWrt

- В секции на вкладке «Куда» добавлен мастер импорта файла или текста WARP-профиля и генерации нового профиля через Cloudflare. Текущее ядро sing-box сохраняется.
- Добавлены подготовка WireGuard/AmneziaWG из настроенных репозиториев с предварительной проверкой зависимостей APK/OPKG, создание отдельного интерфейса и его добавление в секцию, проверка времени рукопожатия.
- Импорт не меняет DNS и маршрут по умолчанию, отклоняет команды запуска и конфликтующие адреса. При отказе применения возвращается исходная конфигурация сети. Для AWG добавлено исключение адресов туннелей из перехвата.
- Ключи передаются через защищённый RPC; временные данные очищаются после операции. Добавлен русский перевод мастера.
- Расширены проверки импорта, отката, фоновых заданий, прав доступа и совместимости OpenWrt, включая ARM64, ARMv7, MIPS и MIPSel.

AmneziaWG требует совместимых с прошивкой пакетов в настроенном репозитории. Доступность API и самого WARP зависит от сети оператора; создание интерфейса не заменяет проверку рукопожатия. Инструкция: [docs/warp.md](https://github.com/slayer326/forkop/blob/main/docs/warp.md).
