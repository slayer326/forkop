Обновление групп и подписок

- Исправлен выбор серверов в URLTest: вместо подходящих узлов больше не подставляется родительская группа подписки.
- В карточке Priority теперь можно раскрыть состав группы: уровни приоритета, серверы, задержки и текущий выбор.
- При сбое системного DNS загрузка подписок использует настроенные Bootstrap DNS. Проверка HTTPS-сертификатов остаётся включённой.
- Если проверка задержки уже идёт, интерфейс сообщает об этом. Старая блокировка после сбоя не мешает запустить новую проверку.
- Запуск Zapret-Manager использует своё зеркало, без возврата к зеркалу автора.
- Исправлены проверки запуска, отложенного reload и восстановления конфигурации. Публикация сборки теперь зависит от результата backend-тестов.

Подписки сторонних провайдеров по HTTPS по-прежнему поддерживаются. Автоматическое исключение серверов не добавлено.
