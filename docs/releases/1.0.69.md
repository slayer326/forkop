## Forkop X 1.0.69 — сортировка, скрытие и копирование серверов

### Сетка серверов на вкладке «Мониторинг»

В разделе «Узлы и группы» у секций с несколькими серверами, например из подписки, появились новые кнопки:

- **«Сортировать по задержке»**: группы вроде Auto остаются сверху, дальше серверы идут от быстрых к медленным, а серверы без ответа — в конце.
- **«Скрыть без ответа»**: прячет серверы, у которых вместо задержки стоит «—». Выбранный сервер и группы не прячутся никогда. Под сеткой показано, сколько серверов скрыто. Из конфигурации при этом ничего не удаляется и не исключается.
- **«Копировать ссылки (N)»**: копирует ссылки всех показанных серверов в том порядке, в каком они видны. Можно отсортировать список, скрыть неотвечающие серверы и вставить оставшиеся ссылки в новую секцию.

Выбор сортировки и скрытия запоминается в браузере отдельно для каждой секции.

### Кнопки на карточке сервера

На карточке каждого сервера появились две кнопки. Первая проверяет задержку только этого сервера, не перепроверяя весь список. Вторая копирует ссылку сервера.

Кнопки проверки и копирования доступны только администратору. В режиме только для чтения ссылки на серверы по-прежнему не передаются в браузер.

Маршрутизация, DNS и настройки не меняются. При обновлении Forkop X служба кратко перезапустится.
