Исправлено исчезновение маршрутов после ручного перезапуска Forkop. При пересборке nftables подсети из встроенных списков, внешних IP-списков и наборов правил снова загружаются из проверенного кэша. Это восстанавливает маршрутизацию Telegram и других сервисов, которые подключаются по IP.

Перед перезапуском Forkop проверяет полную таблицу, включая загруженные подсети. Если кэш нельзя применить, рабочая таблица сохраняется.
