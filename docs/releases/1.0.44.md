## Обновление Forkop X

- Пакеты и список версий Forkop X теперь загружаются с Timeweb; домашнее зеркало используется как резервный источник. GitHub для обновления самого Forkop X больше не нужен.
- Исправлен выбор версии: в списке снова видны выпуски, пакеты которых действительно есть на зеркале, в том числе 1.0.41.
- Перед обновлением и откатом проверяются комплект пакетов и их контрольные суммы на наших серверах.
- Домашнее зеркало получает готовые пакеты с Timeweb, сверяет SHA-256 и публикует список доступных версий.

Настройки и подписки обновление не меняет. Если установленная 1.0.41 отказывается обновляться автоматически, три пакета новой версии понадобится установить вручную один раз.
