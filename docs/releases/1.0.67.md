## Forkop X 1.0.67 — без Zapret Manager

### Zapret Manager удалён из Forkop X

Forkop X больше не устанавливает, не обновляет и не удаляет Zapret Manager. Карточка Zapret-Manager-Stressozz убрана со вкладки «Обновления», а Packet Steering и Direct Proxy заняли её колонку. Из пакета удалены скрипты установки и миграции панели, а обновление Forkop X больше не запускает их в фоне.

Forkop X также больше не удаляет задания автоподбора стратегий Zapret Manager из cron и не показывает, установлен ли он.

Если Zapret Manager или Zapret2 уже стоят на роутере, обновление Forkop X их не трогает: они продолжат работать сами по себе, а удалять их нужно их собственными средствами.

Маршрутизация, DNS и настройки не меняются. При обновлении Forkop X служба кратко перезапустится.
