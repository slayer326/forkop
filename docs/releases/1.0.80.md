## Исправления

- Исправлены имена архивов восстановления при обновлении Forkop на системах с APK.
- Устаревший маркер прерванного обновления больше не откатывает согласованный работающий комплект более новой версии.
- Добавлена проверка SHA-256 перед восстановлением APK из старых архивов с неверным расширением. Неполное или непроверенное состояние сохраняется для ручного восстановления.
- Расширены тесты установки, отката и восстановления для APK и OPKG.
