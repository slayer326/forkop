## Обновление Forkop X

- Пакеты и список версий Forkop X теперь загружаются с Timeweb; домашнее зеркало используется как резервный источник. GitHub для обновления самого Forkop X больше не нужен.
- Исправлен список доступных версий: в него возвращены опубликованные пакеты 1.0.41 и другие выпуски, которые раньше могли пропускаться.
- Восстановление предыдущей версии при обновлении проверяет пакеты и контрольные суммы на наших серверах.
- Синхронизация домашнего зеркала берёт готовые пакеты с Timeweb и проверяет SHA-256 перед публикацией.

Настройки и подписки при обновлении не меняются. Если на 1.0.41 автоматическое обновление уже отклоняется из-за недоступного GitHub, понадобится один раз установить три пакета вручную; перед установкой проверьте контрольные суммы и выполните пробный запуск пакетного менеджера.
