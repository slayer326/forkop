## Forkop X 1.0.66 — Zapret Manager как в Forkop X 2.6

### Zapret2 снова запускается после установки Zapret Manager из панели

Если Zapret Manager устанавливался кнопкой в Forkop X, его установщик создавал каталог `/opt` с правами 0700. Zapret2 при запуске переходит на непривилегированного пользователя, не мог прочитать свои файлы в `/opt/zapret2` и сразу завершался, ничего не написав в журнал.

Теперь все команды из панели Forkop X выполняются с теми же правами на новые файлы, что и из консоли. После обновления Forkop X сам открывает `/opt` на чтение, если Zapret Manager уже установлен, и Zapret2 запускается без ручного `chmod`.

### Установка Zapret Manager

Zapret Manager устанавливается так же, как в Forkop X 2.6: ставится версия панели для Forkop, проверяются её страницы и RPC, а при любой ошибке все затронутые файлы возвращаются в прежнее состояние. После обновления Forkop X панель и команды `zms`, `zmsA` и `zmw` проверяются и при необходимости восстанавливаются. Если Zapret Manager не установлен, ничего не скачивается.

### Диагностика nftables

Предупреждение «Найдены дополнительные правила маркировки» больше не появляется из-за правил Zapret2: они добавляют к метке пакета только свои биты и не трогают бит Forkop X. Предупреждение остаётся для правил, которые могут установить или сбросить бит Forkop X.

Маршрутизация, DNS и настройки не меняются. При обновлении Forkop X служба кратко перезапустится.
