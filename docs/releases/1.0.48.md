## Forkop X 1.0.48

- Исправлен ложный статус «Forkop X не запущен», когда sing-box ненадолго создаёт вспомогательный процесс. Диагностика показывает доступные действия по фактическому состоянию службы.
- При смене сборки sing-box работающая служба сохраняет своё состояние, даже если API кратковременно недоступен.
- DNS-перехват для выделенных входов выполняется до распознавания трафика.
- В мониторинге пользовательские списки показываются по понятным именам вместо технических тегов; параметры URL не выводятся.
- Установка сжатой сборки sing-box расходует меньше места в `/tmp`, сохраняя проверку и откат при ошибке.

Автоматические проверки и сборка пакетов прошли. Установка на роутере пока не проверена.
