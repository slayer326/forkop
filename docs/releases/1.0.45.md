## Forkop X 1.0.45

- Убрали Xbox DNS из готовых вариантов. Сохранённые вручную адреса не меняются.
- Перестроили диагностику: результаты проверок видны сразу, действия и сведения о системе вынесены в отдельную колонку. На узком экране блоки располагаются друг под другом.
- Исправили генерацию DNS-правил для sing-box Extended 1.14 при исключении устройства: пустой фильтр больше не попадает в конфигурацию.
- Домашнее зеркало возобновляет оборванные загрузки, проверяет размер и SHA-256 перед публикацией, сохраняет прежние доступные файлы при ошибке.
- Для старых версий sing-box подготовлен архив на нашем зеркале. Автоматический откат клиента через него пока не включён.
- Устаревшие неопубликованные снимки зеркала очищаются, чтобы они не занимали диск. Рабочие опубликованные файлы остаются на месте.
