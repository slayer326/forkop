## Исправления

- Ручной перезапуск Forkop больше не прерывается из-за недоступности сервера обычных списков, если уже сохранён полный исправный кеш для текущих источников.
- При использовании кеша проверяются целостность файлов и наличие всех настроенных источников. Повреждённый, неполный кеш или кеш от других настроек не разрешает перезапуск с неполными правилами; работающая служба сохраняется.
- Добавлены проверки перезапуска с кешем в ОЗУ, восстановления из flash и отказа при непригодном кеше.
