Исправление установки через APK/OPKG

- Исправлена ошибка `Unable to lock database: Resource temporarily unavailable` при установке и обновлении Forkop на OpenWrt 25.x с `apk`.
- Миграция зеркала больше не запускает вложенный `apk update` или `opkg update` из package post-install/post-upgrade, когда база пакетного менеджера уже заблокирована текущей установкой.
- Ручной запуск миграции зеркала по-прежнему проверяет package index через `apk update`/`opkg update` и сохраняет транзакционный откат при ошибке.
- `forkop.list` теперь обновляется только при фактическом изменении, без лишней перезаписи и повторного обновления индекса.
- Добавлены регрессионные тесты для package post-install и повторного идемпотентного запуска миграции зеркала.
