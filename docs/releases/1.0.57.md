## Forkop X 1.0.57 — безопасное обновление при управляемом sing-box

- Начиная с установленной версии 1.0.57, при последующих обновлениях Forkop X его пакетный хук сохраняет sing-box, установленный как управляемый бинарник. Очистка ядра остаётся только при полном удалении Forkop X.
- Проверка нового и предыдущего набора APK выполняется до остановки работающей службы. При ошибке пакетного менеджера Forkop X сохраняет прежний маршрут и сообщает причину.
- Исправлен адрес архива предыдущей версии sing-box-extended в зеркале для отката.

Для клиента с Forkop X 1.0.53, осиротевшей записью `sing-box-extended` в `/etc/apk/world` и неучтённым ядром требуется отдельная одноразовая корректировка `world` **до** обновления: старый хук выполняется раньше установки новой версии и всё ещё может удалить управляемый sing-box. Если старый хук не исправлять, после обновления ядро придётся устанавливать вручную через панель, но это может не удаться при нехватке места. На известном AX3000T бинарник находится в `/overlay/upper`, а свободно лишь 9,3 МБ; его повторная установка не подтверждена. Безопаснее сначала исправить старый хук, сохранив существующий бинарник. В любом случае сначала проверьте симуляцией APK, что обновляются только три пакета Forkop X и не удаляются kernel-модули.

При успешной установке трёх пакетов Forkop X служба кратко перезапустится. Настройки маршрутизации, DNS и QUIC не меняются.
