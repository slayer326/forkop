## Forkop X 1.0.63 — проверка сайта снова находит правило по списку

### «Проверить сайт или приложение» видит списки

sing-box выводит ответ команды `rule-set match` через свой журнал, то есть в stderr, а Forkop X читал только stdout. Из-за этого ни один список не совпадал, и проверка на вкладке «Диагностика» не могла назвать правило для домена, который выбран списком: для youtube.com она показывала «Правило не рассчитано» вместо секции YouTube.

Теперь ответ читается из обоих потоков, и домены из списков снова получают своё правило и подключение.

- Проверено на роутере: youtube.com — секция YouTube, steampowered.com — «Обход», ya.ru — напрямую.
- Если перед подходящим правилом стоит правило, которое заново определяет адрес домена, маршрут по-прежнему не рассчитывается: он зависит от реального адреса.

Маршрутизация, DNS и настройки не меняются. При обновлении Forkop X служба кратко перезапустится.
