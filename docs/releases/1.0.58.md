## Forkop X 1.0.58 — восстановление обновления sing-box на роутерах с тесным overlay

- Исправлена диагностика осиротевшего hash-pin `sing-box-extended` в `/etc/apk/world`: установка Tiny, Stable и Extended теперь отказывается до остановки службы и сообщает причину.
- Для неучтённого пакетным менеджером бинарника Extended добавлен отдельный режим перехода на Tiny, Stable или новую Extended: сжатая копия в `/tmp` проверяется по SHA-256 до остановки Forkop, после чего старый бинарник освобождает место в overlay. При неудаче пакетной установки предпринимается откат; подробная ошибка `apk` сохраняется в журнале.
- Режим с копией в ОЗУ **не запускается кнопкой панели**. Он требует явного `FORKOP_ALLOW_VOLATILE_SING_BOX_BACKUP=1` при запуске команды через SSH: при отключении питания во время операции копия в `/tmp` исчезнет и может понадобиться ручное восстановление. На обычных устройствах без этого особого состояния порядок обновления не меняется.
- Проверка работы Forkop после смены ядра теперь ограничена реальными 180 секундами. Раньше в лимит не засчитывались сами проверки статуса, и если ядро падало сразу после запуска, откат начинался только примерно через 7,5 минуты.
- В ссылках VLESS, Trojan, Shadowsocks, SOCKS и Hysteria2 разрешены пробелы в отображаемом названии после `#`. Пробелы в адресе, пароле и параметрах подключения по-прежнему отклоняются. Адаптировано из [Forkop X 2.4.4](https://github.com/Screamshow/forkop-x/releases/tag/2.4.4), где исправлен только Trojan.
- К релизу на GitHub приложен файл `SHA256SUMS` с контрольными суммами пакетов.

Для AX3000T с установленной 1.0.57 сначала проверьте `apk del --simulate sing-box-extended`. Если симуляция не удаляет нужные пакеты, можно убрать осиротевшую запись командой `apk del sing-box-extended`, затем повторить `apk add --simulate sing-box-tiny`. Обновите три пакета Forkop X до 1.0.58 отдельно, убедитесь, что Forkop и старый sing-box работают, и только затем по согласованию запускайте миграцию ядра из SSH. Не удаляйте `/usr/bin/sing-box` вручную.

Tiny может не поддержать функции текущей конфигурации Extended. Если проверка запуска Forkop с Tiny не пройдёт, переключение будет считаться неудачным и будет предпринят откат к прежнему бинарнику.
