## Forkop X 1.0.53 — DNS и безопасное применение

- DNS-запросы типа HTTPS теперь получают пустой успешный ответ вместо отказа. Правила FakeIP для A/AAAA не изменены.
- При переключении резервного DNS в системный журнал больше не записывается адрес DNS-сервера, который может содержать приватный путь или токен.
- Если обновление подписки завершилось ошибкой, интерфейс сообщает об этом и предлагает открыть журнал; текст вывода загрузчика с возможными секретами не передаётся в LuCI.
- Защитный снимок перед Save & Apply теперь вызывается настоящим обработчиком страницы LuCI. При невозможности создать снимок изменения не применяются; после применения проверяется подтверждение reload.

Сохранение ручного выбора сервера и лимит файловых дескрипторов уже были реализованы в этой сборке. Поддержка TLS-отпечатков из релиза автора рассчитана на Xrust и не включена для нашего sing-box. Ускоренное подтверждение Save & Apply не включено до проверки на роутере.
