## Forkop X 1.0.68 — XHTTP в подписках и точнее диагностика

### Узлы XHTTP с неподходящими идентификаторами сессии

Если в подписке есть узел XHTTP, чей набор символов и длина идентификатора сессии дают меньше 2^31 вариантов, sing-box отказывался запускаться со всей конфигурацией. Теперь такой узел пропускается с предупреждением в журнале, а остальные узлы подписки работают. Проверка повторяет правило sing-box-extended и podkop-engine: учитываются все длины из диапазона, поэтому, например, `Base62` с длиной `4-8` остаётся рабочим, а `number` с длиной `4-8` пропускается. Узел без длины при заданном наборе символов тоже пропускается.

Если такой узел добавлен вручную ссылкой или JSON, конфигурация не применяется и ошибка сразу называет причину.

### Проверка FakeIP в диагностике

Проверка FakeIP теперь всегда выходит с роутера напрямую. Раньше секция, которая перехватывает весь трафик, забирала и её, и диагностика сообщала, что прямой IP совпадает с IP выхода через VPN.

### Дашборд при удалённом доступе

Если браузер не может подключиться к API ядра напрямую, например при входе в LuCI через Tailscale или когда порт 9090 закрыт, статистика через 5 секунд начинает поступать через LuCI. Раньше виджеты могли долго оставаться в состоянии загрузки.

Маршрутизация, DNS и настройки не меняются. При обновлении Forkop X служба кратко перезапустится.
