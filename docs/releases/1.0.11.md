Своё зеркало и поддержка нескольких платформ OpenWrt

- Добавлена поддержка собственного зеркала `https://mirror.infotechtg.ru` для зависимостей, встроенных списков и OpenWrt package feeds.
- Добавлена миграция со старого зеркала `mirror.51343.ru` с заменой APK-ключа и откатом репозиториев при ошибке обновления индекса.
- Установщик теперь проверяет точное сочетание версии OpenWrt, target, архитектуры и формата пакетов до изменения репозиториев.
- Зеркало поддерживает `mediatek/filogic` с архитектурой `aarch64_cortex-a53` и `rockchip/armv8` с архитектурой `aarch64_generic` для OpenWrt 24.10.0, 24.10.1, 24.10.5 и 25.12.5.
- Сторонние package feeds и произвольные URL подписок сохраняются при миграции.
- Добавлен подписанный APK-репозиторий Forkop и локальная публикация IPK/APK release assets.
- Добавлена автоматическая синхронизация последнего стабильного релиза из GitHub с проверкой размеров и SHA-256 перед публикацией.
- Обновлены контрактные тесты, документация зеркала и проверки миграции конфигурации.
