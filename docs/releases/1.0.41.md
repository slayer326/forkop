## DNS и снимки конфигурации

- Для DNS-правил добавлен выбор готовых серверов: Cloudflare, Google, Quad9, AdGuard, Яндекс и Xbox DNS. После выбора готового варианта поля протокола и адреса скрываются; для ручного ввода остаётся «Свой DNS».
- Яндекс DNS доступен через UDP, DoH и DoT. Добавлена поддержка DoQ для собственных DNS-серверов. DoT и DoQ используют порт 853 — если он заблокирован в сети, выбирайте DoH.
- Xbox DNS можно выбрать через UDP, DoH или DoT в DNS-правилах и резолвере интерфейса. В основных DNS-серверах доступны его адреса и шифрованные варианты; для Bootstrap DNS — только IP-адреса.
- После успешного применения настроек старые снимки автоматически удаляются. Пока новая конфигурация не подтверждена, прежний рабочий снимок сохраняется для отката. Снимок автоподбора DPI также не удаляется, пока он нужен для восстановления.

Адреса подписок и источники обновлений не менялись.
